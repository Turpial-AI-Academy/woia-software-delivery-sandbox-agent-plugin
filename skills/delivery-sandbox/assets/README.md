# Assets

Reusable templates for delivery-sandbox work:

- [sandbox-plan.template.md](sandbox-plan.template.md) — pre-provision plan and boundaries.
- [sandbox-evidence.template.json](sandbox-evidence.template.json) — machine-readable run evidence.
- [sandbox-report.template.md](sandbox-report.template.md) — concise human/agent closeout report.

Templates contain no credentials and must be adapted to actual repository evidence.
